## 一、分析背景与数据口径

本简报基于第 2 周建成的 DWD 星型模型开展探索性分析，全部指标由 Hive 实跑得出（sql/analysis/eda.sql）。

**数据口径**：dwd_order 共 14696 笔订单（已过滤 304 条大额断档脏数据）、覆盖 1000 位用户、366 个日期分区（2024 全年）；核心 KPI 中"有效订单"指订单状态为"已支付"或"已完成"的订单。

## 十、结论与建议

1. **盘子稳健但缺增长**：全年 GMV 2480.56 万元、客单价 2530.41 元，月度窄幅波动无增长趋势，2 月、6 月回落需结合大促节奏复盘；
2. **转化漏斗有流失**：待支付 + 已取消占 27.9%，建议对下单未支付用户做定向催付与优惠券召回；
3. **区域不均**：广东、安徽、北京为洼地，头部门店（开封、北京二店）运营打法可向洼地门店复制；
4. **会员体系待验证**：各等级人均消费无显著差异，第 3 周将以 RFM 模型重构用户分层，替代当前的等级视角；
5. **数据底座可信**：本简报全部指标来自清洗后的 DWD 星型模型，金额分布单峰、枚举收敛、分区裁剪生效，为第 3 周可视化看板提供了可靠取数层。
