# 一、任务与目标

本章对应第 3 周子任务 2：从数仓读取每日 GMV 时间序列，完成趋势与周期分析，构建预测模型对未来 7 天 GMV 进行预测，并给出模型评估与适用边界分析。

- **数据来源**：`ydsh_ads.ads_gmv_daily`（366 天日度有效 GMV，2024-01-01 ~ 2024-12-31），经 beeline 导出为 CSV 后由 pandas 加载；
- **预测目标**：未来 7 天（2025-01-01 ~ 2025-01-07）日度 GMV；
- **评估方式**：时间序列切分（前 336 天训练 / 后 30 天测试，不做随机切分以避免未来信息泄漏），指标 MAE / RMSE / MAPE，并与两个朴素基线对照。

# 二、数据探索与序列特征

| 统计量 | 数值 |
| --- | --- |
| 序列长度 | 366 天 |
| 日均 GMV | 67,774.85 元 |
| 标准差 | 15,577.47 元 |
| 变异系数 CV | 22.98% |
| 日环比标准差 | 37.04% |
| 最大单日跌幅 | -61.25%（2024-11-06） |

![gmv trend](fig_gmv_trend.png)

**特征观察**：

1. 全年 GMV 在 4.3 万 ~ 11.3 万元/天区间波动，无明显的长期上升或下降趋势，月度环比波动在 ±13% 以内；
2. 周内效应微弱：周末均值 68,227.50 元 vs 工作日 67,595.17 元，周末仅高 0.94%，几乎可以忽略；分星期看，周二（69,577 元）与周五（69,123 元）最高，周一（64,931 元）最低，极差仅 7%；
3. 序列噪声大：日环比标准差达 37.04%，日度抖动远大于周期性波动，存在 2024-11-06（-61.25%）这类突发骤降日。

# 三、特征工程

采用监督学习范式，从日度序列构造如下特征：

| 特征 | 含义 | 作用 |
| --- | --- | --- |
| lag1 / lag2 / lag7 | 前 1/2/7 天 GMV | 短期记忆与周周期 |
| ma7 | 近 7 天移动平均 | 平滑趋势项 |
| weekday | 星期几 | 周内效应 |
| is_weekend | 是否周末 | 周末效应（本数据中较弱） |
| month | 月份 | 季节性 |

# 四、模型与评估

在相同训练/测试切分下对比 3 个模型与 2 个朴素基线（测试集为最后 30 天，2024-12-02 ~ 2024-12-31）：

| 模型 | MAE（元） | RMSE（元） | MAPE |
| --- | --- | --- | --- |
| **线性回归（最优）** | **12,290.48** | **14,988.16** | **17.42%** |
| 岭回归（alpha=1） | 12,290.16 | 14,986.54 | 17.42% |
| 梯度提升树 | 13,015.43 | 15,941.09 | 18.38% |
| 基线 1：昨日值（naive lag1） | 16,119.38 | 19,356.65 | 24.66% |
| 基线 2：7 日均值 | 13,074.15 | 14,821.53 | 19.74% |

![test fit](fig_test_fit.png)

**结论**：

1. 线性回归以 MAPE 17.42% 胜出，相对"昨日值"基线降低误差 23.8%，相对"7 日均值"基线降低 11.6%；
2. 梯度提升树反而不如线性模型——这与噪声主导的序列特性一致：树模型倾向记住训练期的随机波动，泛化更差；
3. 从测试集拟合图可见，模型预测曲线明显比真实曲线"平滑"，说明模型学到的是趋势与周期成分，而对突发冲击（如 12-21 的骤升骤降）没有预测能力。

梯度提升树给出的特征重要性佐证了信息来源结构：lag1（23.3%）、lag7（22.8%）、lag2（21.8%）、ma7（18.7%）四项占近九成，month（6.9%）与 weekday（5.2%）贡献有限，is_weekend（0.8%）几乎无用——与第二章"周内效应微弱"的观察互相印证。

# 六、模型适用边界与批判性审视

1. **MAPE 17.4% 只是"平均"水平**：对正常日的预测误差约 10%~15%，但对骤降/骤升日（如 -61.25% 的 11-06）误差可达 60% 以上。若业务需要的是"及时发现异常日"，本模型只能给出置信区间外的偏离提示，不能替代实时监控告警；
2. **递归预测误差累积**：预测第 7 天时，lag1/lag2 来自模型自身输出而非真实值，误差会随步长放大。7 天合计预测的不确定度显著大于逐日预测；
3. **无外生变量**：模型未纳入促销日历、节假日、天气、流量等外部特征。若未来引入大促（如双 11），当前模型必然失效——2024-11-06 骤降若是大促前静默期，模型只会把它当作异常噪声；
4. **样本仅一轮周期**：366 天只覆盖一个年度周期，"月度季节性"实际上无法与噪声区分，month 特征的重要性（6.9%）不应过度解读；
5. **推荐用法**：本模型适合做 1~3 天的运营资源预排（备货、客服排班），不适合做预算承诺。建议配套滚动更新（每周重训）与预测区间（分位数回归）使用。
