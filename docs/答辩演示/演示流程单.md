## 三、三段现场演示的标准动作

### 演示① Superset 仪表板（约 90 秒）

1. 打开 http://localhost:8088，用 **admin / admin** 登录
2. 左侧 **Dashboards** → 打开「云购生活经营分析」
3. 手指屏幕讲一句：**"这是一个数据驱动的仪表板，不是静态截图——6 张图全部实时查 MySQL 镜像层。"**
4. 操作：把**日期筛选器**从默认区间改成"最近 7 天"→ 点 **Apply**
5. 等 2–3 秒，图表刷新，说：**"筛选器联动所有图表，走的是 Superset 的 adhoc filter 下推。"**
6. 鼠标依次划过：GMV 趋势 / 品类占比 / 渠道对比 / 省份分布，每张图一句结论

**若加载慢**：提前把 Dashboard 打开过一次（driver 缓存预热），答辩时直接刷新。

### 演示② ECharts 数据大屏（约 70 秒）

1. 导航页点「数据大屏」，或直接打开 `http://127.0.0.1:8900/云购生活数据大屏.html`
2. **按 F11 全屏**，画面自动按 1920×1080 缩放
3. 讲三层：
   - 顶部 KPI：**GMV 2,480.6 万 / 订单 9,803 / 客单价 2,530.41 / 退款率 5.42%**
   - 中部地图：**15 个省份的销售热力，颜色越深贡献越高**
   - 右侧：品类 TOP8 + 渠道结构 + 门店排行
4. 一句话收尾：**"单文件 HTML，1.6MB，离线可跑，不依赖任何服务——这是给领导汇报用的形态。"**

### 演示③ NL2SQL 智能问答（约 50 秒）

1. 打开 http://localhost:8501
2. 输入框输入：**`整体经营大盘`** → 回车
3. 讲：**"自然语言进，SQL 出，结果自动配图——中间没有任何人工写 SQL。"**
4. 展开「查看生成的 SQL」，指出：**"它自己选中了 ADS 层的 kpi 表，而不是去扫 ODS 明细，这是 schema prompt 里给的语义约束。"**
5. 再问一句 **`各省份销售额排名`**，展示地图/柱状图自动切换

**若 LLM 超时**：提前在终端跑一遍 `python nl2sql/test_nl2sql.py rule` 留一份输出，现场可展示结果并说明是网络原因。

## 四、老师可能追问的问题（预备答案）

| 问题 | 回答要点 |
|---|---|
| 为什么分四层，不分三层？ | ODS 贴源不改一行数据，保留追溯证据；DWD 才承载清洗规则。合并会导致"清洗不可回溯"，出问题查不到原始值 |
| 清洗后行数为什么少了 904？ | −600 是订单号重复去重，−304 是金额异常（>100 万）剔除，对账公式写进了清洗报告第 3 节 |
| 指标口径怎么保证一致？ | 所有指标只在 ADS 层定义一次，DWS 只做汇总不做口径；Superset / 大屏 / Streamlit 三端都读同一张 ads_kpi 表，所以三处数字必然一致（已实测核对） |
| 数据丢了怎么办？ | 已实战演练：`rebuild_pipeline.sh` 一键重建，3 分 25 秒恢复全链路，GMV 与重建前完全一致 |
| 遇到过什么真 Bug？ | 重建脚本不幂等——Hive 外部表 `drop cascade` 不删数据文件，`LOAD` 又是追加语义，导致 ODS 翻倍到 31,200 行。修复方式：重建前物理清理 warehouse 目录 + 脚本加幂等判断 |
| 团队协作怎么留痕？ | 2 个真实 PR 合并 + 双 feature 分支 + 40 余次约定式提交，`docs/Git提交历史.txt` 与审查报告可查 |
| 这个项目能上线吗？ | 能：`docker compose up -d` 六服务一键起，含 healthcheck 与依赖顺序；生产还需补：密钥外置（已用 .env）、Superset 元数据库换 PG、加监控 |

## 五、应急备案

| 故障 | 处理 |
|---|---|
| Docker 起不来 | 直接放大屏（纯静态，不依赖 Docker）+ PPT 里的系统截图讲；Superset / Streamlit 用预录截图（`docs/答辩演示/assets/`） |
| Superset 打不开 | 用 `docs/答辩演示/assets/` 里的仪表板截图，讲"图表是实跑产生的" |
| Streamlit 无响应 | 切终端跑 `python nl2sql/test_nl2sql.py rule`，展示 SQL 与结果 |
| 大屏打不开 | 直接双击 HTML 文件（file:// 也能跑，数据内嵌） |
| 投影分辨率低 | 大屏按 F11 后 Ctrl + 加号放大到 125%，或改用 PPT 内嵌的大屏图 |
