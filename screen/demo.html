一键启动全部服务 在项目根目录执行，首次约 1–2 分钟

# 1) 确认 Docker Desktop 已启动（任务栏鲸鱼图标常亮）
cd C:/Users/21553/WorkBuddy/2026-10-28-17-01-13/ydsh-dw
docker compose up -d

# 2) 等待 hive-server 健康（约 40 秒），确认六服务状态
docker compose ps

# 3) 检查 Hive 四层库是否在线
docker exec hive-server beeline -u "jdbc:hive2://localhost:10000" -n hive -e "show databases"

# 4) 启动大屏静态服务（新窗口，保持不关）
cd screen && python -m http.server 8900

# 5) 打开本导航页
#    http://127.0.0.1:8900/答辩演示导航.html
数据丢了？ 执行 bash rebuild_pipeline.sh，约 3 分半自动重建 ODS→DWS 全链路并校验指标。
只演示大屏？ 双击 云购生活数据大屏.html 即可，file:// 也能跑，数据内嵌不依赖任何服务。
Superset 图表空白？ 首次访问 driver 缓存未热，刷新一次即可；仍空白则 docker restart superset。
Streamlit 无响应？ 终端跑 python nl2sql/test_nl2sql.py rule，直接展示 SQL 与结果。
